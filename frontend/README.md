# Next.js (as Frontend)

## Project Information

- Next.js version: 16.3.8
- Next.js router type: App Router

## Getting Started

1. Install the necessary packages `npm i or npm install`
2. Go to `.env.example` and rename it to `.env`
3. Set the backend dev url `NEXT_PUBLIC_BASE_API_URL=http://localhost:8080/api`
4. Run the dev server `npm run dev`
5. Enjoy!

# Campus Tracker (Backend)

## Project Information

- Build tool: Maven

- Maven version: Maven 3.6.3 or up

- Java version: Java 25 or up

## Getting Start

1. Install the dependecy ```mvn clean install```

2. And run the project ```mvn clean spring-boot:run``` or if you're using Intellij IDEA just navigate to the main class and click run.
